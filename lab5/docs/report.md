# Лабораторная работа №5. Чат-боты

## 1. Краткое описание выбранного трека
Для выполнения работы был выбран **Трек C. TypeBot**. 
TypeBot — это платформа для создания чат-ботов с визуальным конструктором. В рамках работы был выбран готовый шаблон, переведен на русский язык, а также добавлена собственная логика: новые блоки, условия, переменные и интеграция с внешним API через HTTP-запрос.

## 2. Ссылка на бота
[Посмотреть бота в TypeBot](https://typebot.co/lab5-akulchik-obtc78r)

## 3. Использованные AI-промпты
1. *«Придумай текст приветствия для бота-помощника по растениям, чтобы он звучал дружелюбно»*.
2. *«Напиши примеры вопросов для блока "Оцените наш сервис", чтобы узнать мнение пользователя»*.
3. *«Как в TypeBot настроить HTTP Request к API catfact.ninja, чтобы вывести случайный факт о котах в чат?»*.

## 4. Освоенные элементы и блоки
В ходе работы были изучены следующие элементы TypeBot:
*   **Text bubble** (текстовые сообщения).
*   **Input / Choice** (поля ввода и кнопки выбора).
*   **Condition** (условия для ветвления логики).
*   **Variables** (переменные для хранения данных пользователя).
*   **HTTP Request** (интеграция с внешним API).

## 6. Выводы
В ходе лабораторной работы я познакомилась с платформой TypeBot. Больше всего понравилось, что логику бота можно собирать из готовых блоков, как конструктор, и сразу же тестировать в Preview. 
Самым интересным этапом была настройка условия (Condition) и интеграция с внешним API (HTTP Request). Я поняла, как передавать данные из ответа сервера в переменные и выводить их пользователю. 
TypeBot отлично подходит для быстрого создания ботов без необходимости писать код, а возможность экспорта в JSON позволяет сохранять результаты работы.
