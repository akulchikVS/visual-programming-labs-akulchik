

Название процесса: Оплата коммунальных услуг через онлайн-банкинг

Участники (роли):

Плательщик (клиент банка).

Система онлайн-банкинга.

Биллинговый центр (поставщик услуг ЖКХ).

Платежный шлюз.

Шаги процесса:

Плательщик авторизуется в системе онлайн-банкинга и выбирает раздел «Платежи».

Система предлагает выбрать категорию «Коммунальные услуги» и конкретного получателя.

Плательщик вводит лицевой счет и период оплаты.

Система отправляет запрос в биллинговый центр для проверки задолженности.

Биллинговый центр возвращает сумму к оплате и реквизиты.

Ветвление 1: Если сумма корректна, плательщик подтверждает оплату; если нет — процесс возвращается к шагу 3 для уточнения данных.

Плательщик выбирает способ оплаты (с карты или с баланса телефона).

Параллельное действие: Система одновременно резервирует сумму на счете плательщика и отправляет запрос в платежный шлюз для проведения транзакции.

Платежный шлюз обрабатывает запрос и возвращает статус операции.

Ветвление 2: Если оплата прошла успешно, система формирует электронный чек; если произошла ошибка — выводит сообщение об отказе и предлагает повторить попытку.

Система уведомляет биллинговый центр об успешной транзакции для обновления статуса лицевого счета, и процесс завершается.

Условия ветвления:

Ветвление 1 (Проверка суммы): Если сумма совпадает с ожиданиями клиента — переход к оплате; если нет — возврат к вводу данных.

Ветвление 2 (Результат транзакции): Если платеж успешен — формирование чека; если ошибка — уведомление об отказе.
