# API Документация (Node-RED)

## 1. GET /api/text
Возвращает простой текст.
* **Пример запроса:** `http://localhost:1880/api/text`
* **Ответ (200 OK):** `Привет! Это простой текстовый ответ.`

## 2. GET /api/info
Возвращает JSON с двумя полями.
* **Пример запроса:** `http://localhost:1880/api/info`
* **Ответ (200 OK):** `{"status": "success", "message": "Это JSON ответ с двумя полями"}`

## 3. GET /api/items/:id
Возвращает информацию об элементе по его ID.
* **Параметр:** `id` (целое число в пути).
* **Пример успешного запроса:** `http://localhost:1880/api/items/5`
* **Успешный ответ (200 OK):** `{"id": 5, "name": "Элемент 5", "message": "Успешно найдено"}`
* **Пример ошибки (400 Bad Request):** `http://localhost:1880/api/items/0`
* **Ответ (400):** `{"error": "ID не может быть равен 0"}`
* **Пример ошибки (404 Not Found):** `http://localhost:1880/api/items/150`
* **Ответ (404):** `{"error": "Элемент с таким ID не найден"}`
