# Лабораторная работа №2. Node-RED

## 1. Краткое описание выполненного
В ходе лабораторной работы был освоен инструмент визуального программирования Node-RED. 
Была произведена установка Node-RED через Docker с использованием volume для сохранения данных. 
Собраны и задеплоены базовые и расширенные потоки (flows), демонстрирующие работу с инжектами, функциями, ветвлением, шаблонами, сетевыми запросами, MQTT-брокером, созданием REST API, панелью Dashboard, Telegram-ботом, файловой системой и контекстом.

## 2. Использованные AI-промпты (ключевые примеры)
В процессе работы использовался ИИ для генерации шаблонного кода и решения точечных проблем:
* **Для Function node (2.2, 2.3):** *"Сгенерируй код на JavaScript для ноды function, который берет число из payload, создает массив через цикл for и возвращает объект с полями status и array. Используй let/const и if/else"*.
* **Для Template node (2.5):** *"Как написать Mustache-шаблон в Node-RED чтобы он выводил текст с подстановкой трех переменных из объекта msg.payload"*
* **Для исправления ошибки:** *"В Node-RED при выполнении функции вылезает ошибка `RangeError: Invalid array length".
* **Для Telegram-бота (2.10):** *"Напиши код для function node который принимает сообщение от telegram receiver проверяет команду /start и /lab"*

## 3. Освоенные ноды
В ходе работы были изучены и применены следующие ноды:
* `inject`, `debug` (базовые)
* `function` (написание JS-кода)
* `switch` (ветвление потоков)
* `change` (изменение свойств msg)
* `template` (Mustache-шаблоны)
* `http request` (GET-запросы к API)
* `mqtt in` / `mqtt out` (работа с публичным брокером)
* `http in` / `http response` (создание GET-эндпоинтов)
* `gauge`, `chart` (из плагина Dashboard)
* `telegram receiver`, `telegram sender` (создание бота)
* `file in` / `file out` (чтение и запись файлов)
* Работа с `flow context` (сохранение состояния между сообщениями)

## 4. Способ установки и версии
* **Способ установки:** Docker (официальный образ `nodered/node-red`). Использован volume для сохранения данных (`-v "${PWD}/lab2/node-red-data:/data"`).
* **Версия Node-RED:** v5.0.9
* **Версия Node.js:** v24.22.2
