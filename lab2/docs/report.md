\# Лабораторная работа №2. Node-RED



\## Часть 1. Установка и запуск



Способ установки: Docker (официальный образ `nodered/node-red`).

Используется volume для сохранения данных между перезапусками. Порт: 1880.



Версии:

\- Node-RED: v5.0.9

\- Node.js: v24.22.2



Собранный поток (Flow 01):

Создан базовый поток `inject -> debug`. 

\- Нода `inject` каждые 5 секунд отправляет строку с фамилией.

\- Топик: `lab2/akulchik/basic`.

\- Нода `debug` настроена на вывод `complete msg object` (полного объекта сообщения).
