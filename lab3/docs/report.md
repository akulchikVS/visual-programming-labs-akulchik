## Часть 2. Исследование идеи

**Изученные Build Guides:**
1. Registration and Login Pages.
2. Project Information Page.

**Что полезно:** 
В гайде по регистрации понятно описана связка User с другими данными (я проверила, что ИИ сгенерировал её правильно). Гайд по Project Info показал, как выводить данные из базы и настраивать кнопки.

**Что взяла:** 
Строго по гайду создала страницу «Project Information» с Data Type `ProjectInfo`. Настроила workflows: клик по email открывает почту, клик по соцсетям — открывает сайты.
