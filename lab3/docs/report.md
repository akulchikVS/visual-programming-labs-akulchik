# Лабораторная работа №3. Bubble

## 1. Краткое описание выполненного
В ходе лабораторной работы было создано веб-приложение «Каталог растений» на no-code платформе Bubble. 
Каркас приложения был сгенерирован с помощью встроенного AI-агента Bubble. Затем вручную были доработаны UI-элементы (добавлены глобальные переменные и стили), внедрен готовый компонент из библиотеки.
Также была спроектирована база данных (создан Data Type `Plants`), заполнены тестовые записи и настроена полная CRUD-логика (Create, Read, Update, Delete) через Workflows.

## 2. Промпт дословно (из Части 1)
> Создай приложение на тему «Каталог растений».
> Пусть этот сайт будет требующий регистрацию.
> Страницу обязательно создай по структуре header + body + footer.
> Обязательно укажи в заготовке следующую строку: «ТВП: Акулчик».
> Добавь несколько интерактивных элементов (реализующих CRUD).

## 4. Использованные AI-промпты (дословно)
Помимо основного промпта для генерации каркаса (указан в п.2), использовались следующие промпты:

**Для создания страницы информации:**
> Создай в приложении базу данных (Data Type) с названием ProjectInfo. Добавь в неё следующие поля: Project Name (тип text), Contact Email (тип text), Contact Phone (тип text), Social Media Links (тип list of texts). Затем создай новую страницу (Page) и назови её Project Information. Добавь текстовые элементы, которые будут выводить данные из базы ProjectInfo. Настрой логику: клик по email открывает почту, клик по иконкам соцсетей открывает сайты.

**Для создания сущности в Части 4.1:**
> Придумай 3-4 поля разных типов для сущности "Plants" (Растение) в каталоге растений. Нужны поля для названия, даты посадки, сложности ухода и ссылки на фото.

## 5. Какие элементы и workflows освоены
**Элементы (UI):**
* Глобальные переменные (Global Variables) для задания основного цвета (primary-color).
* Создание и применение кастомных стилей (Styles).
* Использование готовых блоков из библиотеки компонентов (раздел Marketing -> Testimonials).
* Работа с элементами Text, Input, Button, Picture Uploader.

**Workflows (Логика):**
* `Create a new thing` (Создание новой записи в базе данных из формы на странице).
* `Make changes to a thing` (Обновление/редактирование данных существующей записи).
* `Delete a thing` (Удаление записи из базы).
* `Do a search for` (Вывод списка данных в Repeating Group).
* `Open an external website` (Открытие ссылок на соцсети).

## 7. Выводы
В ходе работы я познакомилась с платформой Bubble. Больше всего понравилось, как AI-агент с нуля генерирует структуру страницы (header, body, footer) буквально за минуту. 
Самым сложным, но и самым интересным этапом было проектирование базы данных и настройка CRUD-workflows. Я поняла, как важно правильно настроить типы данных (Data Types), чтобы логика (создание и удаление) работала без ошибок. 
Bubble отлично подходит для быстрого прототипирования, и теперь я понимаю разницу между статичным дизайном и динамическими приложениями с базой данных.
