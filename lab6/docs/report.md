\## 1. Описание базового приложения

В среде Kodular было создано приложение «Приветствие». 

На экране `Screen1` реализованы следующие компоненты:

\- \*\*Label\*\* — заголовок «Введите имя»;

\- \*\*Label\*\* — обязательная метка с фамилией на английском языке (Akulchik), видимая при запуске;

\- \*\*TextBox\*\* — поле для ввода имени (со свойством Hint = «Ваше имя»);

\- \*\*Button\*\* — кнопка «Поздороваться»;

\- \*\*Label\*\* — для вывода результата приветствия.



\*\*Логика работы (блоки):\*\*

При нажатии на кнопку срабатывает условный блок `if / then / else`. С помощью блока `Logic (=)` проверяется, пустой ли текст в TextBox. Если пустой — выводится сообщение «Введите имя!». Если нет — с помощью блока `Text (join)` склеивается строка «Привет, » + введенное имя.



\## 2. Реализованные Ачивки



\*\*Ачивка 5: Расширение (Extension)\*\*

\- В проект было добавлено стороннее расширение \*\*Animation Utilities\*\* (найдено в сообществе Kodular).

\- Данное расширение позволяет делать кастомные анимации компонентов, выходящие за рамки стандартных.



\*\*Ачивка 11: Анимация\*\*

\- С использованием расширения Animation Utilities настроена анимация для кнопки «Поздороваться».

\- При нажатии на кнопку срабатывает блок `call Animation\_Utilities1.Bounce Vertical`. 

\- Настроены параметры: `component = Button1`, `start Position = 0`, `end Position = 50`, `duration = 500`. Кнопка подпрыгивает вверх при нажатии.



\*\*Ачивка 8: Уведомления (Notifier)\*\*

\- На экран добавлен невидимый компонент \*\*Notifier\*\* (раздел Connectivity).

\- После успешного формирования приветствия (в ветке `else`) вызывается блок `call Notifier1.ShowAlert` с текстом «Успешный вход!».

В ходе работы были учтены ограничения бесплатного аккаунта Kodular:

\- Доступно до 10 активных проектов (в рамках лабы использован 1);

\- Объем загружаемых ассетов (медиафайлов) не должен превышать 10 МБ (в проекте ассеты не использовались);

\- Можно устанавливать до 5 расширений на проект (использовано 1 расширение — Animation Utilities).

Данные лимиты не были превышены, работа велась в рамках бесплатного тарифа.
